# MalawiHub Smart Keyboard

A native Android Input Method Editor for MalawiHub Smart Writer and other Android text fields.

Features:
- Android-style compact keyboard layout
- Floating/resize-friendly IME window behavior
- Shift control without forced capitalization
- Enter/new-line support
- Backspace and selection deletion
- Works as a system keyboard after the user enables it in Android keyboard settings

Package: mw.malawihub.keyboard
Version: 1.0.0
