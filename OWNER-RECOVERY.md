# MalawiHub Owner Recovery Checklist

## If the phone is lost

The phone is not required to own or recover MalawiHub.

1. Use another trusted phone or computer.
2. Sign in to the GitHub account `malawhub`.
3. Open https://github.com/malawhub/malawihub
4. Open https://malawihub.pages.dev/
5. Sign in to Cloudflare to manage the Pages deployment.
6. Sign in to Supabase to manage the database and backend.

## Recovery material that must exist outside the phone

- GitHub password stored in a secure password manager.
- GitHub recovery codes stored in a password manager and/or offline printed copy.
- A second GitHub authentication method such as a passkey or security key.
- Cloudflare backup codes stored outside the phone.
- Recovery access to the primary email account.

## Important

Never put recovery codes, passwords, private keys, or service-role secrets in this repository. Never send them to an AI assistant, collaborator, or anyone else.
