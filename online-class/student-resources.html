How offline notes work

1. Connect to the internet and sign in. 2. Open this page so the latest note and paper lists are saved on this device. 3. Open a resource and use its download option, or tap Save file offline when supported. 4. Later, return to this page from your browser history or the hub while offline.

Some external file hosts block offline saving from a webpage. For those files, use the host's normal download button while online. This page does not bypass account permissions or make live classes work offline.
