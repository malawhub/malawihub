👩‍🏫 Teacher Guide — English

1. Sign in and open your Teacher Dashboard.
Use your MalawiHub teacher account. Open Teacher Dashboard, choose one of your classes, then open Teacher Workspace when you need private document and AI help.
2. Open your PDF privately.
In Teacher Workspace, enter/open the class, choose the PDF from your phone or computer, and wait for it to be read. The original file remains on your device; this page does not upload the PDF.
3. Use the PDF privately.
You can read the PDF, ask the private Teacher AI for a lesson plan, notes, assignment, quiz, test or marking guide, and prepare your lesson before showing anything to students.
4. Display PDF notes to students when you want.
After the PDF has been read, press Display to Students. MalawiHub extracts the readable text from the PDF and places it in the class's Live Notes. Students already inside the Live Class can see the notes automatically.
5. Explain and control what students see.
Only press Display to Students when the material is ready. You can stop the display with Stop Display. Your original PDF and private AI conversation remain private.
6. Teach normally.
Start the live class, use the microphone, share your screen when needed, use chat, and explain the displayed notes. You can also add/edit Live Notes directly during the class.
7. End the class.
Use End Class when the lesson is finished. Students will be notified that the class has ended.
Important: A normal text PDF works best. A scanned PDF that contains only pictures may not produce readable text. For such a PDF, use screen sharing or prepare a text-based version before publishing.

Teacher quick checklist

  • Sign in with a teacher account.
  • Open the correct class code.
  • Check the PDF before publishing.
  • Use AI privately for preparation.
  • Press Display to Students only when ready.
  • Confirm students can see the Live Notes.
  • Stop display when you no longer want the notes shown.
  • Do not share private documents or private AI answers accidentally.

👩‍🏫 Buku la Aphunzitsi — Chichewa

1. Lowani mu akaunti yanu ya aphunzitsi.
Lowani mu MalawiHub ndi akaunti ya teacher. Tsegulani Teacher Dashboard, sankhani class yanu, kenako tsegulani Teacher Workspace ngati mukufuna kugwiritsa ntchito zikalata ndi AI mwachinsinsi.
2. Tsegulani PDF mwachinsinsi.
Mu Teacher Workspace, lowetsani class yomwe mukuphunzitsa ndipo sankhani PDF pa foni kapena kompyuta yanu. PDF yoyambirira imakhalabe pa chipangizo chanu; tsamba ili silitumiza PDF yonse ku MalawiHub.
3. Gwiritsani ntchito PDF mwachinsinsi.
Mukhoza kuwerenga PDF, kufunsa Teacher AI kuti ikuthandizeni kupanga lesson plan, notes, assignment, quiz, test kapena marking guide. Zimene AI ikuyankha zimakhala zachinsinsi kwa aphunzitsi.
4. Sonyezani notes za PDF kwa ophunzira mukafuna.
PDF ikatha kuwerengedwa, dinani Display to Students. MalawiHub imatulutsa mawu omwe angawerengedwe mu PDF ndikuyika mu Live Notes ya class. Ophunzira omwe ali kale mu Live Class adzawona noteszo zokha.
5. Sankhani zimene ophunzira awone.
Musadinye Display to Students mpaka mutawerenga ndi kutsimikiza kuti zomwe mukufuna kuwonetsa ndi zolondola. Dinani Stop Display mukafuna kusiya kuwonetsa notes. PDF yanu yoyambirira ndi zokambirana zanu ndi AI zimakhalabe zachinsinsi.
6. Pitirizani ndi phunziro.
Yambitsani live class, gwiritsani microphone, share screen ngati pakufunika, gwiritsani chat, ndipo fotokozani notes zomwe ophunzira akuona.
7. Malizitsani class.
Dinani End Class mukamaliza phunziro. Ophunzira adzadziwitsidwa kuti class yatha.
Chofunika: PDF yomwe ili ndi mawu osankhidwa bwino imagwira bwino kwambiri. PDF yomwe ndi zithunzi zokha kapena scanned pages ingalephere kutulutsa mawu. Mukakumana ndi zimenezi, gwiritsani screen sharing kapena konzekerani mtundu wa PDF/notes womwe uli ndi mawu.

Checklist ya aphunzitsi

  • Lowani ndi teacher account.
  • Tsegulani class code yolondola.
  • Werengani PDF musanayionetse.
  • Gwiritsani AI mwachinsinsi pokonzekera phunziro.
  • Dinani Display to Students pokhapokha ngati mwakonzeka.
  • Onetsetsani kuti ophunzira akuona Live Notes.
  • Dinani Stop Display mukafuna kusiya kuwonetsa notes.
  • Musagawane mwangozi zikalata zachinsinsi kapena mayankho a AI.

🎓 Student Guide — English

1. Get the class code.
Your teacher gives you a class code such as CHEM101 or MH-ABC123. Keep the code exactly as provided.
2. Join the Live Class.
Open MalawiHub Online Class, enter the class code and your name, then choose Join as Student. You do not need teacher permissions.
3. Wait for the teacher.
You will see the live class area and wait for the teacher to start. Keep your internet connection stable.
4. Read notes displayed by the teacher.
When the teacher chooses Display to Students for a PDF, the readable PDF notes appear in Live Notes. You do not need to download the teacher's PDF.
5. Follow the lesson.
Read the notes while listening to the teacher. Use class chat when you need to ask a question or respond to the teacher.
6. Use video resources.
If the teacher adds lesson videos, they appear under Class Video Resources. Watch them inside the class where possible instead of downloading large files.
7. Save notes if allowed.
You can use Download Notes or Print/Save PDF for your own study when those controls are available. Respect your teacher's instructions about copying or sharing materials.
8. When the class ends.
When the teacher ends the class or the timer reaches zero, the lesson is finished. Rejoin using the correct code if your teacher schedules another session.
Privacy: Students cannot see the teacher's private Teacher Workspace, private documents, or private AI conversation. Students only see material the teacher deliberately places in the class, such as Live Notes, shared videos, chat and the live lesson.

🎓 Buku la Ophunzira — Chichewa

1. Pezani class code.
Aphunzitsi anu adzakupatsani class code monga CHEM101 kapena MH-ABC123. Lembani codeyo molondola.
2. Lowani mu Live Class.
Tsegulani MalawiHub Online Class, lowetsani class code ndi dzina lanu, kenako dinani Join as Student. Simufunika teacher permissions.
3. Dikirani aphunzitsi.
Mukalowa mudzaona malo a live class ndipo mudzadikira aphunzitsi kuti ayambe. Onetsetsani kuti internet yanu ili bwino.
4. Werengani notes zomwe aphunzitsi awonetsa.
Aphunzitsi akadina Display to Students pa PDF, mawu a PDF omwe angawerengedwe adzaoneka mu Live Notes. Simuyenera kutsitsa PDF ya aphunzitsi.
5. Tsatirani phunziro.
Werengani notes pamene mukumvetsera aphunzitsi. Gwiritsani ntchito class chat ngati mukufuna kufunsa funso kapena kuyankha.
6. Gwiritsani ntchito ma video a class.
Aphunzitsi akawonjezera ma video a phunziro, adzaoneka mu Class Video Resources. Ngati zingatheke, onerani mu class m'malo motsitsa mafayilo akuluakulu.
7. Sungani notes ngati zololedwa.
Mukhoza kugwiritsa ntchito Download Notes kapena Print/Save PDF ngati zilipo. Tsatirani malangizo a aphunzitsi okhudza kukopera kapena kugawana zinthu za phunziro.
8. Class ikatha.
Aphunzitsi akamaliza class kapena timer ikafika zero, phunziro limatha. Ngati pali session ina, gwiritsani class code yomwe aphunzitsi akupatsani.
Chinsinsi: Ophunzira sangathe kuona Teacher Workspace ya aphunzitsi, zikalata zachinsinsi, kapena zokambirana zachinsinsi ndi AI. Amaona zinthu zomwe aphunzitsi asankha kugawana mu class, monga Live Notes, ma video, chat ndi live lesson.

Quick help / Thandizo lachangu

Teacher: If PDF text is not extracted, try a text-based PDF or share the screen. If students do not see published notes, make sure they are in the same class code and refresh the Live Class.
Teacher / Aphunzitsi: Ngati PDF siyikutulutsa mawu, gwiritsani PDF yomwe ili ndi text kapena share screen. Ngati ophunzira sakuwona notes, onetsetsani kuti ali mu class code yomweyo ndipo ayambitsenso Live Class.
