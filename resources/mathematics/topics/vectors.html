1. Introduction

A vector is a quantity that has both magnitude and direction. Examples include displacement, velocity and force.

Learning objectives

  • Understand vectors and scalar quantities.
  • Represent vectors using diagrams and column vectors.
  • Add and subtract vectors.
  • Multiply vectors by scalars.
  • Find the magnitude of a vector.
  • Use vectors to describe movement between points.
  • Solve geometric problems using vectors.

2. Scalars and Vectors

Scalar Vector
Has magnitude only Has magnitude and direction
Mass Displacement
Time Velocity
Distance Force
Distance is a scalar, while displacement is a vector.

3. Representing Vectors

A vector can be written using a column vector:

\[ \mathbf{a}= \begin{pmatrix} 3\\ 2 \end{pmatrix} \]

This means 3 units horizontally and 2 units vertically.

4. Equal Vectors

Two vectors are equal when they have the same magnitude and the same direction.

The vectors \[ \begin{pmatrix}3\\2\end{pmatrix} \quad\text{and}\quad \begin{pmatrix}3\\2\end{pmatrix} \] are equal.

5. Addition of Vectors

Corresponding components are added.

\[ \begin{pmatrix} a\\b \end{pmatrix} + \begin{pmatrix} c\\d \end{pmatrix} = \begin{pmatrix} a+c\\b+d \end{pmatrix} \]
\[ \begin{pmatrix}2\\3\end{pmatrix} + \begin{pmatrix}4\\1\end{pmatrix} = \begin{pmatrix}6\\4\end{pmatrix} \] Therefore: \[ \boxed{ \begin{pmatrix}6\\4\end{pmatrix}} \]

6. Subtraction of Vectors

\[ \begin{pmatrix} a\\b \end{pmatrix} - \begin{pmatrix} c\\d \end{pmatrix} = \begin{pmatrix} a-c\\b-d \end{pmatrix} \]
\[ \begin{pmatrix}7\\5\end{pmatrix} - \begin{pmatrix}2\\3\end{pmatrix} = \begin{pmatrix}5\\2\end{pmatrix} \] \[ \boxed{ \begin{pmatrix}5\\2\end{pmatrix}} \]

7. Multiplying a Vector by a Scalar

A scalar is an ordinary number. Multiplying a vector by a scalar changes its magnitude and may reverse its direction if the scalar is negative.

\[ k \begin{pmatrix} a\\b \end{pmatrix} = \begin{pmatrix} ka\\kb \end{pmatrix} \]
\[ 3 \begin{pmatrix} 2\\4 \end{pmatrix} = \begin{pmatrix} 6\\12 \end{pmatrix} \]

8. Magnitude of a Vector

For: \[ \mathbf{a}= \begin{pmatrix} x\\y \end{pmatrix} \] the magnitude is:

\[ |\mathbf{a}|=\sqrt{x^2+y^2} \]
Find the magnitude of: \[ \mathbf{a}= \begin{pmatrix} 3\\4 \end{pmatrix} \] \[ |\mathbf{a}|=\sqrt{3^2+4^2} \] \[ =\sqrt{25} \] \[ \boxed{5} \]

9. Position Vectors

A position vector describes the position of a point relative to the origin.

If \(A(x,y)\), then: \[ \vec{OA}= \begin{pmatrix} x\\y \end{pmatrix} \]

If \(A(4,7)\), then: \[ \boxed{ \vec{OA}= \begin{pmatrix} 4\\7 \end{pmatrix}} \]

10. Vector Between Two Points

The vector from \(A\) to \(B\) is:

\[ \vec{AB}=\vec{OB}-\vec{OA} \]
Let: \[ A(2,3),\qquad B(7,8) \] Then: \[ \vec{AB}= \begin{pmatrix} 7\\8 \end{pmatrix} - \begin{pmatrix} 2\\3 \end{pmatrix} \] \[ = \begin{pmatrix} 5\\5 \end{pmatrix} \] Therefore: \[ \boxed{ \vec{AB}= \begin{pmatrix} 5\\5 \end{pmatrix}} \]

11. Parallel Vectors

Two vectors are parallel if one is a scalar multiple of the other.

Consider: \[ \mathbf{a}= \begin{pmatrix}2\\3\end{pmatrix} \] and \[ \mathbf{b}= \begin{pmatrix}6\\9\end{pmatrix} \] Since: \[ \mathbf{b}=3\mathbf{a} \] the vectors are parallel.

12. Geometric Applications

Vectors can be used to prove relationships in geometric figures such as triangles and parallelograms.

When working with a geometric vector problem, identify the starting point and ending point carefully. The order of the letters determines the direction.

For example: \[ \vec{AB}=-\vec{BA} \]

13. MANEB-style Practice

  1. Add: \[ \begin{pmatrix}3\\4\end{pmatrix} + \begin{pmatrix}2\\5\end{pmatrix} \]
  2. Subtract: \[ \begin{pmatrix}8\\7\end{pmatrix} - \begin{pmatrix}3\\2\end{pmatrix} \]
  3. Find: \[ 4\begin{pmatrix}2\\3\end{pmatrix} \]
  4. Find the magnitude of: \[ \begin{pmatrix}5\\12\end{pmatrix} \]
  5. Find \(\vec{AB}\) when \(A(3,2)\) and \(B(9,7)\).
  6. Determine whether \[ \begin{pmatrix}2\\4\end{pmatrix} \quad\text{and}\quad \begin{pmatrix}6\\12\end{pmatrix} \] are parallel.
  7. If \[ \vec{OA}= \begin{pmatrix}4\\3\end{pmatrix} \] and \[ \vec{OB}= \begin{pmatrix}9\\8\end{pmatrix}, \] find \(\vec{AB}\).

Answers

  1. \[ \begin{pmatrix}5\\9\end{pmatrix} \]
  2. \[ \begin{pmatrix}5\\5\end{pmatrix} \]
  3. \[ \begin{pmatrix}8\\12\end{pmatrix} \]
  4. \(13\)
  5. \[ \begin{pmatrix}6\\5\end{pmatrix} \]
  6. Yes, because the second vector is \(3\) times the first.
  7. \[ \begin{pmatrix}5\\5\end{pmatrix} \]

14. Common Mistakes

  • Reversing the direction of a vector.
  • Adding coordinates incorrectly.
  • Forgetting that a negative scalar reverses direction.
  • Confusing a vector with its magnitude.
  • Using \(AB\) when the question requires \(\vec{AB}\).
  • Forgetting to subtract the starting position from the final position.
Examination tip: Always write the vector as a column vector and keep the direction clear. For a vector from \(A\) to \(B\), use final position minus initial position.
