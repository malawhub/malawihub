1. Introduction to Functions

A function is a rule that connects an input to an output. The input is usually represented by \(x\), while the output is represented by \(y\).

A function can be written as \(f(x)\), which means "the value of the function when the input is \(x\)".
If \[ f(x)=2x+3 \] find \(f(4)\). Substitute \(x=4\): \[ f(4)=2(4)+3 \] \[ =\boxed{11} \]

2. Coordinates

A point on a Cartesian plane is written as \((x,y)\). The first coordinate is the horizontal position and the second coordinate is the vertical position.

The origin is the point \((0,0)\).

3. Quadrants

Quadrant x-coordinate y-coordinate
I Positive Positive
II Negative Positive
III Negative Negative
IV Positive Negative
The point \((-3,5)\) lies in Quadrant II because \(x\) is negative and \(y\) is positive.

4. Linear Functions

A linear function produces a straight-line graph.

\[ y=mx+c \]

where:

  • \(m\) is the gradient;
  • \(c\) is the \(y\)-intercept.
For \[ y=3x+2 \] the gradient is: \[ \boxed{3} \] and the \(y\)-intercept is: \[ \boxed{2}. \]

5. Gradient of a Straight Line

The gradient measures how steeply a line rises or falls.

\[ m=\frac{y_2-y_1}{x_2-x_1} \]
Find the gradient through \((2,3)\) and \((6,11)\). \[ m=\frac{11-3}{6-2} \] \[ =\frac{8}{4} \] \[ \boxed{m=2} \]
A positive gradient means the line rises from left to right. A negative gradient means the line falls from left to right.

6. Drawing a Straight-Line Graph

To draw a graph such as:

\[ y=2x+1 \]
construct a table of values.
\(x\) -2 -1 0 1 2
\(y=2x+1\) -3 -1 1 3 5

Plot the coordinates and join them using a straight line.

7. Intercepts

y-intercept

The \(y\)-intercept occurs where the graph crosses the \(y\)-axis. At this point: \[ x=0. \]

For \[ y=4x-6 \] put \(x=0\): \[ y=4(0)-6=-6. \] Therefore the \(y\)-intercept is: \[ \boxed{(0,-6)}. \]

x-intercept

The \(x\)-intercept occurs where: \[ y=0. \]

For \[ y=2x-8 \] put \(y=0\): \[ 0=2x-8 \] \[ 2x=8 \] \[ x=4. \] Therefore: \[ \boxed{(4,0)}. \]

8. Quadratic Functions

A quadratic function has the form:

\[ y=ax^2+bx+c \]

Its graph is called a parabola.

If \(a>0\), the parabola opens upward. If \(a<0\), the parabola opens downward.
Consider: \[ y=x^2 \] Some values are:
\(x\) -2 -1 0 1 2
\(y\) 4 1 0 1 4
The graph is symmetrical about the \(y\)-axis.

9. Real-Life Graphs

Graphs can represent real situations such as distance travelled, time, temperature, population and financial changes.

When interpreting a real-life graph, identify:

  • what each axis represents;
  • the units used;
  • the scale;
  • increasing and decreasing sections;
  • maximum and minimum values;
  • the gradient where appropriate.
MANEB examination tip: Before answering a graph question, carefully read both axes and their units. Many incorrect answers result from using the wrong scale.

10. Practice Exercises

  1. Find \(f(5)\) if \(f(x)=3x-2\).
  2. State the quadrant containing \((-4,-7)\).
  3. Find the gradient through \((1,2)\) and \((5,10)\).
  4. State the gradient and \(y\)-intercept of: \[ y=4x-3. \]
  5. Find the \(x\)-intercept of: \[ y=3x-12. \]
  6. Complete the table for: \[ y=x+2 \] when \(x=-2,-1,0,1,2\).
  7. State whether \(y=-2x+5\) has a positive or negative gradient.

Answers

  1. \[ f(5)=13 \]
  2. Quadrant III.
  3. \[ m=2 \]
  4. Gradient \(=4\), \(y\)-intercept \(=-3\).
  5. \[ x=4 \]
  6. \(0,1,2,3,4\)
  7. Negative gradient.

11. Common Mistakes

  • Writing coordinates as \((y,x)\) instead of \((x,y)\).
  • Using the wrong scale on graph axes.
  • Confusing gradient with the intercept.
  • Forgetting that the \(x\)-intercept has \(y=0\).
  • Forgetting that the \(y\)-intercept has \(x=0\).
  • Plotting points inaccurately.
Final tip: Use a sharp pencil, clearly label axes, include units where necessary and show enough working to make your method understandable.
